# VPS SOC Analyzer

**Автор: Тыневье Денис**

Мини-SOC для учебного анализа журналов VPS. Проект обнаруживает неудачные
SSH-входы и подозрительные веб-запросы, оценивает риск, проверяет TCP-порты
на localhost и контролирует SHA-256 целостность файла.

## Запуск

```bash
python -m unittest test_vps_soc.py
python vps_soc_main.py
```

Конвейер использует искусственные журналы и временный каталог; он не изменяет
системные файлы и проверяет порты только на `127.0.0.1`.
